## Опис проєкту

Проєкт складається з двох частин:

1. **Завдання 1 (ООП):** Реалізація моделі користувача, адміністратора, сесії та системи логування (AuditLog) з безпечним хешуванням паролів алгоритмом PBKDF2.
2. **Завдання 2 (FIM):** Консольна утиліта (File Integrity Monitor) для відстеження несанкціонованих змін у файлах (модифікація, створення, видалення) за допомогою порівняння хеш-сум SHA-256.

## Інструкція із запуску

Програма використовує CLI-інтерфейс (через `argparse`) та має єдину точку входу — файл `main.py`. Всі команди виконуються з кореневої папки проєкту.

### 1. Демонстрація Завдання 1 (Система авторизації)

Команда запускає симуляцію роботи системи користувачів (вхід, помилки валідації, запис подій в аудит):

```bash
python -m labs.lab02.main demo
```
