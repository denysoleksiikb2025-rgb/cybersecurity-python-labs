# Реєстр вразливостей мережевих сервісів (Варіант 2)

Сервіс обліку результатів навчальної перевірки мережевих сервісів. 
- **Одиниця вимірювання (value):** оцінка небезпеки (score) від 0 до 10.
- **Поріг:** 6.0.
- **Категорії:** mail, vpn, dns.
